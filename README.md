# Sora Deliverables

A compact repository for three Sora-related prototype deliverables:

1. `creative_workflow_builder`
2. `prompt_assistant`
3. `sora-data-files-export`

The repository is organized so each deliverable lives in its own folder, with its related single-file HTML artifact inside that folder. A compiled presentation covering `creative_workflow_builder` and `prompt_assistant` is placed at the repository root.

---

## Repository Structure

```text
sora/
├── README.md
├── <presentation-file>.pdf
├── creative_workflow_builder/
│   └── https://ereyes.github.io/sora/creative_workflow_builder/creative_workflow_builder.html
├── prompt_assistant/
│   └── sora_prompt_builder.html
└── sora-data-files-export/
    └── sora-gallery.html
```


---

## Deliverables

| Deliverable | Folder | Primary artifact | Notes |
|---|---|---|---|
| Creative Workflow Builder | `creative_workflow_builder/` | `creative_workflow_builder.html` | Prototype HTML experience for building or documenting creative workflows. |
| Prompt Assistant | `prompt_assistant/` | `prompt_assistant.html` | Prototype HTML assistant for structuring, improving, or reusing Sora prompts. |
| Sora Data Files Export | `sora-data-files-export/` | `sora-data-files-export.html` | Prototype HTML artifact related to explore our Sora data files. |
| Presentation | Repository root | `<presentation-file>.pptx` | PDF overview for `creative_workflow_builder` and `prompt_assistant`. |

---

## How to Use

Clone or download the repository, then open the HTML files directly in a browser.

No build step is required if each deliverable remains a self-contained, single-file HTML artifact.
