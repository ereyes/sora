# Creative Workflow Builder — Archive Note

**Date:** May 25, 2026  
**Artifact:** `creative_workflow_builder.html`

## One-sentence summary

Creative Workflow Builder is a standalone HTML prototype that helps a creative practitioner capture a core idea, list the tools used in the process, add inspiration or image-reference notes, and generate an exportable visual workflow map.

## Original conversation brief

The work began from the need for a lightweight document where a user could input information about their creative workflow. The desired structure included a large text area for the overall idea, editable fields for the names of tools used in the workflow, and a place to point to image references or inspiration. The intended interaction was: enter the material, click **Go**, generate a visual workflow, and download the resulting diagram.

## Prototype translation

The conversation was translated into a browser-based prototype with four main capture layers:

1. **Project title** — a concise identifier for the workflow.
2. **Core idea** — the main concept, prompt, or creative direction.
3. **Tools** — repeatable fields for naming and describing tools, systems, models, apps, materials, or process steps.
4. **Inspiration / references** — repeatable fields for reference links, image notes, source cues, or aesthetic direction.

When the user clicks **Go**, the prototype converts these inputs into a visual workflow map. The map can then be downloaded as **SVG** or **PNG**.

## Implemented features

- Standalone single-file HTML prototype.
- Textarea for the central creative idea.
- Dynamic tool fields.
- Dynamic inspiration/reference fields.
- **Go** button that generates a visual workflow.
- Download as **SVG** and **PNG**.
- Save workflow data as **JSON**.
- Import workflow data from **JSON**.
- Load-sample and clear actions.
- Local autosave in the browser.

## Why this is useful for the archive

The prototype makes the creative process more legible. Instead of preserving only the finished work, it preserves the relationships among idea, tools, and references. This gives future reviewers a clearer sense of how the work was made and what influenced it.
